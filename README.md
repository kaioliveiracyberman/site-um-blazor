# SiteUmBlazor

Projeto da disciplina de **Desenvolvimento Web** (Usabilidade, Dev. Web, Mobile e Jogos), feito com **Blazor no .NET 10**. Reúne quatro páginas que praticam roteamento, eventos de clique, estado e renderização condicional.
